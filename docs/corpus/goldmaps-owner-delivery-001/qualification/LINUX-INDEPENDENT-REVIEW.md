signal 9 before producing full map receipts. Resource exhaustion was the leading
explanation; kernel OOM counters were unavailable. Only these owned jobs were
stopped, original logs were retained, bulk staging was moved from shared memory
to disk, and serial execution completed the full required population. Those
interrupted outcomes are not map incompatibility verdicts.

No local displayed runtime claim is made because the environment's Xorg socket
restrictions blocked local graphical execution. Three packaged material-plane
previews were visually inspected for intact landscape/portrait orientation and
framing; those are labelled material visualizations, not GPU captures.
